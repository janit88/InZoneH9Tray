# InzoneH9Tray

[English](README.md) | **Русский**

## Индикатор заряда Sony INZONE H9 / H7 для системного трея Windows

InzoneH9Tray — небольшая программа для Windows, которая показывает уровень заряда и состояние зарядки наушников Sony INZONE H9 и Sony INZONE H7 в системном трее.

Программа считывает заряд напрямую через USB/COM-интерфейс беспроводного донгла Sony и не требует постоянно открытого окна INZONE Hub.

## Возможности

* Показывает уровень заряда наушников в системном трее Windows.
* Показывает состояние зарядки.
* Автоматически находит COM-порт по идентификатору `VID_054C&PID_0E53`.
* Не привязана к конкретному номеру COM-порта.
* Записывает текущий статус в текстовые файлы рядом с программой.
* Показывает `BUSY`, если INZONE Hub запущен и занял COM-порт.

## Поддерживаемые устройства

Проверено на:

* Sony INZONE H9

Предположительно также работает с:

* Sony INZONE H7

Оба устройства используют следующий аппаратный идентификатор:

```text
VID_054C&PID_0E53
```

Работа с Sony INZONE H7 пока не подтверждена непосредственным тестированием.

## Ограничение

INZONE Hub и InzoneH9Tray используют один и тот же COM-интерфейс беспроводного донгла.

Если INZONE Hub запущен, он занимает COM-порт, поэтому InzoneH9Tray не может прочитать уровень заряда. В этом случае значок в трее показывает:

```text
BUSY
```

Для постоянного отображения заряда необходимо полностью закрыть INZONE Hub, включая его значок в системном трее.

## Установка готовой версии

1. Скачайте `InzoneH9Tray.exe` со страницы **Releases** репозитория.
2. Запустите скачанный файл.
3. Значок программы появится в системном трее Windows.
4. Если Windows скрыла значок, нажмите стрелку `^` и перетащите его на видимую часть панели.

## Автозапуск вместе с Windows

1. Нажмите `Win + R`.
2. Введите:

```text
shell:startup
```

3. Поместите в открывшуюся папку ярлык на `InzoneH9Tray.exe`.

## Сборка из исходного кода

Установите необходимые зависимости:

```powershell
py -m pip install --upgrade pyserial pystray pillow pyinstaller
```

Соберите исполняемый файл:

```powershell
py -m PyInstaller --onefile --noconsole --clean --name InzoneH9Tray --hidden-import=pystray._win32 inzone_tray.py
```

Готовый исполняемый файл будет находиться по адресу:

```text
dist\InzoneH9Tray.exe
```

## Файлы статуса

Программа создаёт рядом с исполняемым файлом следующие файлы:

```text
inzone_battery.txt
inzone_battery_status.txt
inzone_tray_error.log
```

Они могут использоваться для диагностики и интеграции с другими программами или виджетами рабочего стола.

## Статусы значка

| Значок | Значение                             |
| ------ | ------------------------------------ |
| `70`   | Текущий уровень заряда               |
| `20`   | Низкий уровень заряда                |
| `BUSY` | COM-порт занят программой INZONE Hub |
| `NO`   | Наушники или донгл не найдены        |
| `?`    | Ошибка чтения уровня заряда          |
